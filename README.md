# JS - Treinos e Anotações de Programação

Este repositório é um conjunto de arquivos simples em **JavaScript** com explicações e treinos práticos para fixar fundamentos de programação.

A ideia é funcionar como um **caderno pessoal**, onde cada arquivo aborda um tema e pode ser executado separadamente.

---

## Estrutura

Os conteúdos ficam dentro da pasta `JS/`, separados por assunto:

- `comparadores.js` — comparações e operadores lógicos aplicados na prática
- `condicionais.js` — if/else e variações
- `escolha.js` — estruturas de escolha (ex: switch/case)
- `exercicios.js` — exercícios práticos para treinar lógica
- `hoisting.js` — explicações e exemplos sobre hoisting
- `lacoFor.js` — laço `for` e usos comuns
- `legibilidade.js` — boas práticas, clareza, organização e estilo
- `operadoresComparacao.js` — `==` vs `===`, comparações e armadilhas
- `operadoresMatematicos.js` — operações matemáticas e cálculos básicos
- `script.js` — arquivo geral (testes soltos / rascunhos)
- `tipos.js` — tipos, `typeof` e conversões básicas

> Observação: os arquivos são independentes. A intenção é abrir um por vez, entender e executar.

---
